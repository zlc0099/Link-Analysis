## 1. 当前阶段与开工门

- 当前处于 **M0 设计评审**：四份文档完成后暂停，等待用户确认后再编码（决策 D-07）。

## 5. 验收清单

- [ ] 1. URL：标准 / `.git` / `git@` / 尾部斜杠 / 简写均可用；非 GitHub、私有、空仓库提示正确
- [ ] 2. 中等仓库（<300 文件）60 秒内出报告；进度可见；可取消
- [ ] 3. 四类检查均有证据（文件:行、commit 固定链接）；Windows 脚本为信息项
- [ ] 4. 每个失分项可展开到规则 ID 与证据；P0 封顶 39 生效
- [ ] 5. 覆盖率不足 / Tree 截断 / 文件失败有明确横幅，不伪造满分
- [ ] 6. Markdown 导出含 repo / branch / sha / 分析时间 / 覆盖率 / 脱敏证据
- [ ] 7. 单元测试覆盖全部规则 ID（正反例）与评分边界（100 / 76 / 39）
- [ ] 8. 3 个公开仓库验证并记录 commit；人工抽查 5 条证据
- [ ] 9. 页面 1440 / 768 无横向滚动；错误 / 限流 / 截断态可用；控制台无报错
- [ ] 10. GitHub Pages 在线可用；README 链接可访问；重新部署成功
- [ ] 11. README 更新跟踪四问齐全；`AI_USAGE.md` 含至少 1 条真实 AI 纠错记录
- [ ] 12. 仓库与导出不含完整密钥；截图不含真实密钥；Token 不出现在 URL / 日志
- [ ] 13. 用本工具分析 Link-Analysis 自身，结果与预期一致并记录
- [ ] 14. 未实现能力（AI、增量对比）在 README 中明确标注「设计 / 未实现」

## 6. 测试矩阵

| 类型 | 用例 | 期望 |
|---|---|---|
| 单元 | 8 种 URL 形式 + 5 种非法输入 | 正确解析或就地报错 |

| E2E（开发期） | 首页 → 示例仓库 → 报告 → 导出 | 全链路通过 |

| 真实数据 | 3 个公开仓库 | 记录 commit 与摘要；抽查证据 |

| 部署 | Pages 冒烟 | 线上可分析、无 404 资源 |

## 7. 风险与兜底

| 风险 | 影响 | 兜底 |
|---|---|---|
| 匿名限流（60 次/时）影响开发与评审 | 分析失败 | Token 入口、raw CDN 不占额度、本地缓存、错误提示；测试用 mock |
| 密钥规则误报 / 漏报 | 评分失真、口碑风险 | 占位符白名单、测试路径降级、置信度标签、真实仓库回归、README 声明 |
| 超大仓库 / 超时 | 报告不完整 | 400 文件上限 + 覆盖率横幅 + 进度 + 取消；演示选中小仓库 |
| Pages 基路径 / 构建配置 | 线上空白 | Day 1 部署演练；相对 base；无路由 |
| 48h 时间不足 | 交付不完整 | 预设裁剪线（§8）；P0 保底，P1 可降级 |
| 演示仓库被推送保护拦截 | 演示失败 | 只用假值 `.env`，不使用真实格式 Key；测试字面量运行时拼接 |
| 公开仓库 / push 未获授权 | 无法交付 | M5 前与用户确认账号、仓库名、可见性，再执行 |
| 泄露真实仓库密钥到截图 | 伦理与合规风险 | 截图只用演示仓库 / fixture；报告全程脱敏 |

## 8. 裁剪线

- **P0 保底**：四类检查、可解释评分、报告页、错误/限流/截断态、Markdown 导出、commit 标注、Pages、README、AI_USAGE、真实仓库验证
- **P1 可降级**：报告缓存 / 最近列表、复检对比、分享链接、Windows 作用猜测、blob 级增量实现
- **P2 直接放弃**：差异视图、ETag、GitLab、AI 实现、历史趋势、私有仓库

裁剪顺序：先降级 P1，再压缩 P2；评分口径、脱敏、覆盖率提示、commit 标注不可降级。

## 9. 需要用户配合

1. 评审四份设计文档，确认范围、评分口径、页面结构（当前步骤）
2. M5 前提供 GitHub 账号 / 用户名，确认仓库名与公开可见性；**创建与 push 前再次确认**
3. 决定是否创建问题演示仓库（P-02）
4. 决定 LICENSE（默认 MIT，P-03）
5. 开发期如遇匿名限流，可临时提供只读 Token（P-04，非必须）
6. 提交前一起检查 README 与 `AI_USAGE.md` 的表述是否真实、无夸大

## 10. Definition of Done

- 验收清单 1–14 全部通过，且每条有可复现的验证方式
- `npm run build` 与单测通过；Pages 线上可用
- README 含更新跟踪四问、评分口径、验证记录、已知限制
- `AI_USAGE.md` 含工具清单、验证方法、至少 1 条真实 AI 纠错记录
- 仓库无真实密钥、无伪造成绩、未实现能力明确标注
- 首笔提交包含设计文档（文档先行可追溯）
